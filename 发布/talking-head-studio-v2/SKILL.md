# 口播与封面工作室 v2

这是独立新版本，不修改 personal-talking-head-edit 或 douyin-modeled-cover。入口统一，剪辑、字幕、语义动效、音频、封面、文案分别执行。仅使用当前素材与用户明确指定的参考；不要求历史项目或固定路径。

## 开始前讨论

先读取已有项目的 `project.json`、`BRIEF.md` 与本轮要求。新项目读 [讨论与参数](references/intake.md)，检查素材后向用户汇总推荐配置：发布平台、横竖屏或双版本、构图方式、分辨率和帧率、节奏、字幕、动效、声音、封面模式、交付范围及技术路线。

**先讨论，再制作。** 给出简洁且可修改的配置方案，等用户明确接受后再剪辑、生成付费素材或渲染。用户已明确参数或说“按这些做”即视为接受；不要重复问已回答的问题。仅修改已确认项目时，沿用配置，只讨论真正影响此次修改的未决项。安装与只读检测可在讨论期间完成。

默认推荐：Remotion + FFmpeg；横竖屏每次讨论；分辨率/帧率参考当前素材；中等语义动效、清晰中文字幕、以人声为主；建模封面 1080×1440 与 1440×1080；成片、可编辑工程、封面与发布文案。默认值是建议，不是替用户确认。

从 [项目参数模板](assets/project.template.json) 复制生成项目自己的 `project.json`。模板 `status: draft` 与空的 `video.outputs` 表示尚未确认，不可直接开工。将确认结果写入配置，保存确认依据到 `BRIEF.md`。记录参数修改与完成阶段，支持中途恢复。

## 工具先行

任何视频制作前均检测 Node、npm、FFmpeg、FFprobe、Remotion、HyperFrames 和浏览器；即使本次只用一种渲染器，也记录另一种是否可用。

运行 `node <skill>/scripts/preflight.mjs --toolchain <工具目录> --report <项目>/environment.json`。允许安装时加 `--install`；工具与浏览器将安装在指定目录/工具自身缓存内，不改旧 skill，不全局安装，不静默更新已有锁文件。实际工具链目录由项目配置指定。

脚本会验证版本、两套 CLI、渲染浏览器并解析 HyperFrames doctor 的 `ok` 与分项结果。总体 `ok` 是本地视频渲染必需项就绪；doctor 的完整结果另存，可选 Docker/TTS 等未装不会伪装为全部通过。失败项必须解决或明确报告后才进入依赖它的步骤。FFmpeg/FFprobe 与 Node 缺失由当前系统包管理器安装；不把检测失败当成工具可用。详见 [工具与渲染路线](references/renderers.md)。

## 按需执行模块

- **剪辑/字幕/音频/动效**：读 [口播制作](references/editing.md)，用实际录音定位句子和剪点。视频框架入口存在时先读 hyperframes；本项目明确默认选择 Remotion，可保持这个选择。选 HyperFrames 时再读取其 core、CLI 与所需领域规范，避免另开一轮重复访谈。
- **封面**：读 [封面制作](references/covers.md)。默认使用生成式人物重建；可显式选真实帧。生图时加载可用的 imagegen 指南；不依赖旧封面 skill 才能工作。仅封面任务不安装视频框架。
- **发布文案**：从实际视频写一条标题、第一人称正文、自然互动问题与少量相关标签，存为 `publishing.md`。不得虚构结果或替用户发布。
- **局部修改**：锁定已认可部分，按当前要求修改；不要重写已认可字幕、换参考人物或重做背景。只重跑受影响模块和检查。

## 复用与交付

项目目录建议保留 `project.json`、`BRIEF.md`、`environment.json`、`timeline.json`、`assets/`、`source/`、`exports/`、`covers/`、`publishing.md` 与 `qa.md`，只建立实际需要的文件。`timeline.json` 保存源素材剪点、最终时间轴映射、字幕和动效语义点；工程使用相对素材路径并带依赖锁文件。

交付前读 [质量检查](references/qa.md)。逐路验证画幅、字幕安全区、画面与音频完整性、声音、剪接与封面身份。未经检查不要宣称通过。交付说明真实帧或生成式人物重建的区别，以及缺失依赖或尚未完成项。

## 扩展约定

新增平台、画幅、渲染器、封面风格或模块时读 [扩展接口](references/extensions.md)。共享配置与剪辑时间轴作为稳定边界，渲染器只负责实现；不要把某次项目的比例、接口密钥、人物姿态或历史路径写死到通用流程。
