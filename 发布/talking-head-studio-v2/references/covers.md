# 封面制作

## 模式与身份

`modeled`：默认生成式重建同一人物的完整上身，产生写实 3D 质感图像；它不是可编辑三维网格。`frame`：用当前真实照片/视频帧作构图，不声称做了建模。`none`：跳过。不得因生图工具不可用擅自改成普通抠图并称完成建模。

身份优先级：本轮指定身份照片/姿态 > 当前视频身份帧 > 明确选用的历史样例。风格参考里的人物不作为身份。选帧要清晰、眼睛睁开、表情自然、没有说话扭曲；不必使用旧项目。可查看包内 `assets/approved-3x4.jpg` 与 `approved-4x3.jpg` 作为历史风格参考，当前新要求优先。

建模必须把真实身份图传入参考图编辑接口，不能仅凭文本随机生人。保留脸型、眼形与间距、眉毛、鼻唇、下颌、发际线、自然不对称、年龄、肤色、发型、衣着。先保证像本人，再增加柔和定向光、皮肤细节、衣料与适度立体层次；防止美颜换脸、大眼睛、蜡像皮肤、小头大身或拉长躯干。

姿态来自当前参考：自然坐姿、抱臂或解释手势可以保留，不默认强加微笑、点赞或模特站姿。完整双肩、上身及需要显示的手势，五指与腕肘肩连接可信；仅保留参考已有配饰。原帧截断手时可仅用脸肩作身份参考，重建时做克制补全。

## 生成与接口

默认沿用创作者已有设置：`https://image.fushengyunsuan.cn/v1`、`gpt-image-2`、`quality=low`，可在项目配置覆盖。密钥从当次安全环境取得；不写进配置、提示词、日志、图片元数据或交付文件，不读取/打印无关凭据。

人物使用兼容的 `POST /images/edits` 传真实身份图；背景可用 `POST /images/generations`。旧版记录 2026-10-11 的编辑接口、`b64_json` 和人物 1024×1536/背景 1536×1024 可用；这是历史参考，不等于本次可用，调用前按当前工具支持确认。优先使用当前可用的图像生成工具或 imagegen CLI，不在 skill 内复制易过期的客户端。

该默认模型不使用透明背景参数；要独立人物可请求纯绿底，实际查看返回后才决定抠图。可配置其他支持透明的模型。生成响应可能是黑底、渐变或光晕，不可盲目套绿幕公式。人物满意而背景不对时仅编辑背景，锁定身份、发型、衣着、姿态和手部，再检查漂移。

默认每资产最多 3 次生成尝试；用户给了预算则优先遵守。连续相同失败两次先诊断，不无限付费重试；达到上限就报告问题与可选方案。接口、身份图或必要凭据缺失时可继续不依赖它的剪辑与排版方案，不能把未生成的封面当成成品。

## 构图与中文

默认 1080×1440（3:4）与 1440×1080（4:3）各自构图，也支持新比例。人物是主视觉，脸有足够视觉分量，双肩、手势与标题合理完整；横版不能简单裁竖版。

背景从当前主题派生、明显虚化且不抢人；旧版工作台只是示例，不把任何视频都套同一房间/工厂。人物与背景匹配光向、色温、明暗和接触阴影，避免硬轮廓、发丝孔隙、绿边与贴纸感。

中文标题由本地确定性排版完成，字形准确，不依赖模型拼字。默认风格参考为珊瑚红主题词、白色结果词、深描边、小号深底黄字标签；允许随参考和平台变化。主标题回答一个问题，再补真实结果/过程，有限强调色与图标，留出层级和间距。示例“2–3天 → 10分钟”只在当前视频确实说到时使用，不夸大个人体验。

## 修改与交付

先检查人物原图的相似度、比例、肢体，再排版；保留头、肩、手与腰部的生成余量。原尺寸与手机缩略图都看。已认可的内容锁定，“只改人物”就保留标题、信息、配色与背景。未经明确认可不写成批准样例，不覆盖旧批准图。

最终逐张检查脸、眼睛、牙齿、手、肩、发丝、色边、文字与安全区。保留生成来源与最终两版，清理旧版仅在用户要求时做。交付明确说明人物经过生成式重建；真实帧模式则准确说明来源。
