# 讨论与项目参数

先探测素材尺寸、帧率（含可变帧率）、旋转、时长、色彩/HDR、音轨、可用身份图与脚本，区分“素材本身参数”和“交付参数”。讨论时说清推荐理由与代价；不要一次抛出几十个技术问题。

第一轮通常合并三组问题：

1. 发布到哪里，横屏 16:9、竖屏 9:16、双版本还是自定义比例？各版本是完整内容还是另做精简版？
2. 剪辑节奏、字幕样式与动效密度希望怎样？有无参考、必须保留/删除的段落、目标时长？
3. 是否采用建模人物封面双比例与发布文案？需要可编辑工程吗？沿用 Remotion 还是选择 HyperFrames？

用户未关心的技术项给推荐配置统一确认，不要求逐项回答。既有项目只讨论变更项。已确认后不再为可逆实施细节逐次索要许可；发布、上传或新的外部付费服务仍按实际授权范围执行。

| 参数 | 建议及决策依据 |
| --- | --- |
| `video.outputs` | 各自保存 id、width、height、fps、fit、safe_area；横竖分别构图，不以改宽高替代重排 |
| 输出尺寸 | 横屏常用 1920×1080，竖屏 1080×1920；高分辨率按素材与平台决定，不盲目放大 |
| fps | 参考当前素材和平台；混帧率/VFR 先确认时间轴基准，避免盲目设 60fps |
| fit | `reframe`（跟随主体/重要物体）、`contain`（保全网页与信息）、`layout`（人物与图解重排）；裁切前检查脸和手 |
| 安全区 | 每平台/画幅以像素保存，参考当次平台 UI；模板值仅为建议，必须在实际构图检查 |
| `edit` | 脚本结构、停顿保留、目标时长、删减范围、章节导航；不给句尾固定危险剪点 |
| `captions` | 是否烧录、SRT/ASS、字体、每版字号/行宽、强调方式、位置；文字与录音一致 |
| `motion` | `none/light/medium/dense`，语义图形优先；统计图只用实际数据或明确概念示意 |
| `audio` | 单/双声道、响度与真峰值、降噪、BGM、音效、自动避让人声；默认 BGM 关闭 |
| `cover` | `modeled/frame/none`，身份图、风格参考、尺寸、中文标题、主题背景、生成模型和质量 |
| `delivery` | 成片格式、编辑工程、字幕、封面、文案、是否需要预览确认；默认确认后完成制作，不增加重复审批 |
| `renderer` | Remotion 主路线、HyperFrames 可选；切换时保留配置与素材，不暗中换框架 |

配置优先级：本轮用户明确要求 > 当前已确认项目配置 > 用户明确指定的参考/习惯 > 本 skill 的建议。封面画幅与视频画幅独立。建模的 `quality: low` 是生图质量参数，成片编码质量独立设置。

允许 `extensions` 保存新能力的命名空间参数；已知字段拼写错误应纠正，未知扩展字段保留并解释当前是否执行。把不能推断但确实阻塞的问题集中问一次。
