# 口播与封面工作室 v2

新版在 `talking-head-studio-v2/`，旧版未改。当前文件夹中的 `.video-toolchain/` 是单独安装的 Remotion 与 HyperFrames 本地环境，不是 skill 的组成部分。

以后可以这样开始：

> 使用当前文件夹 talking-head-studio-v2/SKILL.md，先和我讨论视频横竖屏、字幕、动效、声音、封面及交付参数，确认后再制作。

也可以说“只做封面”“只改人物”“改成横竖双版本”。每次先读取已有项目配置，沿用已确认部分，不重复访谈。

如果要让 Codex 自动发现此版本，可把整个 `talking-head-studio-v2` 文件夹复制到自己的 skills 目录；本次仅按要求交付在这里，没有替换或安装到旧 skills 目录。

## 默认建议

Remotion + FFmpeg 为主，HyperFrames 为可选路线；横竖屏每次讨论。默认交付成片、可编辑工程、1080×1440 与 1440×1080 的建模封面、发布文案。生图沿用原封面 skill 的接口、gpt-image-2、quality=low，密钥在实际使用时提供，不保存在包内。

## 环境检查

在当前文件夹运行：

```powershell
node ./talking-head-studio-v2/scripts/preflight.mjs --toolchain ./.video-toolchain --browser ./.video-toolchain/node_modules/.remotion/chrome-headless-shell/win64/chrome-headless-shell-win64/chrome-headless-shell.exe --report ./environment.json
```

缺少 npm 工具或渲染浏览器时加 `--install`。上面的 `--browser` 适用于本机已安装的官方浏览器，覆盖本次进程中原先指向系统 Chrome 的设置，不改全局变量。其他电脑可省略它先安装，或提供自己的已验证浏览器路径。检查结果见 `environment.json`；`ok: true` 表示本地渲染必需项通过，不表示 Docker、离线 TTS、离线音乐生成等可选能力均安装。新电脑仍要重新检查，系统级 Node 与 FFmpeg 按系统环境安装。

`talking-head-studio-v2.zip` 用于保存和迁移 skill，包含说明、参数模板、脚本与原批准封面参考，不包含体积大的 node_modules。本包不是已制作的视频；实际口播工程和输出在未来项目中生成。
